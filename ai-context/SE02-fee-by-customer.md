# SE.02 — Xem Code phí theo Khách hàng

## Mô tả chung

- **Mục đích**: Cho phép người dùng tra cứu chính sách phí áp dụng cho một KH hoặc một nhóm KH bằng cách tạo bộ lọc các điều kiện tính phí theo KH.

### Layout và chức năng trên màn hình

| STT | Layout | Chức năng | Mô tả |
|-----|--------|-----------|-------|
| 1 | Search Bar (phía trên) | Tìm kiếm | Tìm kiếm theo Mã KH cụ thể hoặc tạo bộ lọc điều kiện tính phí |
| 2 | Cây thư mục (bên trái) | | Tổ chức thư mục hình cây tương ứng với các cấp SPDV |
| 3 | | Thư mục | Click → hiển thị thông tin chi tiết SPDV + thư mục con |
| 4 | Thông tin chi tiết (bên phải) | | Hiển thị thông tin chi tiết SPDV phù hợp với điều kiện tìm kiếm |
| 5 | | Code phí đi kèm | Hiển thị khi SPDV là cấp cuối |
| 6 | | Xem | Xem chi tiết từng code phí |
| 7 | | Biểu phí đi kèm | Hiển thị khi SPDV không phải cấp cuối |
| 8 | | Xem | Xem chi tiết biểu phí và code phí trực thuộc |
