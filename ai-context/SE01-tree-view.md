# SE.01 — Xem nghiệp vụ theo cây thư mục

## Mô tả chung

- **Mục đích**: Cho phép người dùng xem toàn bộ danh mục sản phẩm dịch vụ và các biểu phí/code phí đang có hiệu lực theo tổ chức thư mục hình cây.

### Layout và chức năng trên màn hình

| STT | Layout | Chức năng | Mô tả |
|-----|--------|-----------|-------|
| 1 | Cây thư mục (bên trái) | | Tổ chức thư mục hình cây tương ứng với các cấp SPDV đã khai báo |
| 2 | | Tìm kiếm | Cho phép tìm kiếm gần đúng theo tên thư mục |
| 3 | | Thư mục | Click vào thư mục → hiển thị thông tin chi tiết SPDV + các thư mục con |
| 4 | Thông tin chi tiết (bên phải) | | Hiển thị thông tin chi tiết SPDV được chọn |
| 5 | | Code phí đi kèm | Hiển thị khi SPDV là cấp cuối → danh sách code phí gắn với SPDV |
| 6 | | Xem | Xem thông tin chi tiết từng code phí |
| 7 | | Biểu phí đi kèm | Hiển thị khi SPDV không phải cấp cuối → danh sách biểu phí gắn với SPDV |
| 8 | | Xem | Xem thông tin chi tiết biểu phí và các code phí trực thuộc |

## Màn hình tham khảo

- Màn hình xem SPDV
- Màn hình Code phí đi kèm SPDV
- Màn hình danh sách code phí đi kèm
- Màn hình xem chi tiết code phí
- Màn hình Biểu phí đi kèm SPDV
- Màn hình danh sách biểu phí đi kèm
- Màn hình xem chi tiết biểu phí
