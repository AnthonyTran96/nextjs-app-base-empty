# PR.04 — Danh sách Code phí chưa sử dụng

## Mô tả chung

- **Mục đích**: Cho phép người dùng xem danh sách các Code phí chưa sử dụng trong hệ thống (ở trạng thái Chờ gán hoặc Ngừng hoạt động).

### Trạng thái Code phí

| STT | Trạng thái | Mô tả |
|-----|------------|-------|
| 1 | Hoạt động | Code phí đang gán với một Biểu phí có hiệu lực |
| 2 | Ngừng hoạt động | Code phí đang gán với một Biểu phí hết hiệu lực |
| 3 | Chờ gán | Code phí chưa được gán với biểu phí nào |

### Chức năng trên màn hình

| STT | Chức năng | Mô tả |
|-----|-----------|-------|
| 1 | Xem | Cho phép xem bản ghi |
| 2 | Lọc | Cho phép tìm kiếm dữ liệu trên lưới |
| 3 | Tải xuống | Cho phép tải xuống dữ liệu trên lưới ra file |
